# Katana — суши-бар в Самарканде

Одностраничный сайт для компьютера и телефона. Пять экранов идут одним кадром: Самурай → Сакура → Кухня → Путь клинка → Контакты. Анимации на GSAP + ScrollTrigger, языки русский и английский.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка всех пяти экранов |
| `css/style.css` | Стили. Цвета бренда — в начале файла (`:root`) |
| `js/i18n.js` | **Все тексты RU / EN и ссылки** (карта, Instagram, Яндекс Еда). Менять тексты и ссылки — здесь |
| `js/main.js` | Анимации: прокрутка-«камера», лепестки, заставка, параллакс от мыши |
| `assets/img/` | Сжатые фото для сайта |

Папка `materials/` с исходниками в репозиторий не попадает (она в `.gitignore`).

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub (или откройте существующий `katana-samarkand`).
2. Загрузите в него содержимое этой папки: `index.html`, `css/`, `js/`, `assets/`, `.nojekyll`, `README.md`.
3. В репозитории: **Settings → Pages → Branch: `main`, папка `/ (root)` → Save**.
4. Через минуту сайт откроется по адресу `https://<ваш-ник>.github.io/<имя-репозитория>/`.

Сборка не нужна: это обычные HTML, CSS и JS. GSAP и шрифты грузятся с CDN.
